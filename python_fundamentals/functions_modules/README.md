# [Python - Functions & Modularity](./)

## [islower.py](./islower.py) - Checks whether a given character is a lowercase letter from a to z and returns True or False

## [uppercase.py](./uppercase.py) - Takes a string and converts each lowercase character to its uppercase equivalent using its ASCII value.

## [print_last_digit.py](./print_last_digit.py) - Prints and returns the last digit of a given number.

## [pow.py](./pow.py) - Calculates a number raised to a given exponent, including negative exponents.

## [add.py](./add.py) - Demonstrates how to use the if __name__ == "__main__" condition to execute code only when the module is run directly

## [calculation.py](./calculation.py) - Demonstrates how to import and use several functions from another module to perform calculations.

## [variable_load.py](./variable_load.py) - Demonstrates how to import a variable from another module and access its value when the script is executed directly.
