# [exception_handling](./)

## [safe_print_list.py](./safe_print_list.py) - Demonstrates how to use try, except, and finally to safely access elements of a list.

## [safe_print_integer.py](./safe_print_integer.py) - Demonstrates how to safely print an integer while handling ValueError and TypeError exceptions.

## [safe_print_list_integers.py](./safe_print_list_integers.py) - This file contains a function that safely prints the first `x` elements of a list that are integers. It skips non-integer values by handling `TypeError` and `ValueError` exceptions, and returns the number of integers successfully printed.


## [safe_print_division.py](./safe_print_division.py) - This file contains a function that safely divides two numbers, prints the result, and returns it. If the division by zero occurs, the function handles the `ZeroDivisionError`, prints `None`, and returns `None`.


## [raise_exception.py](./raise_exception.py) - Intentionally raised a TypeError

## [raise_exception_msg.py](./raise_exception_msg.py) - Raised a NameError with a message
