[base_geometry.py](./base_geometry.py): Defines the BaseGeometry class with methods for calculating areas and validating positive integers.

[1-rectangle.py](./1-rectangle.py): Defines a Rectangle class that inherits from BaseGeometry, with a private width and height validated by integer_validator().

[2-rectangle.py](./2-rectangle.py):
Extends Rectangle with an area() implementation and a string representation in the format [Rectangle] <width>/<height>.

[1-square.py](./1-square.py): Defines a Square class that inherits from Rectangle, with a private size used as both width and height, and its own area() method.

[2-square.py](./2-square.py): Extends Square with its own string representation in the format [Square] <width>/<height>, demonstrating method overriding and polymorphism.
